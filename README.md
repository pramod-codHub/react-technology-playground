
# ⚛️ React Learning Hub

A collection of hands-on React projects, practical examples, and experiments covering React fundamentals and its modern ecosystem.

This repository is created to learn, practice, and explore different React technologies, libraries, state management solutions, and development patterns through small, real-world projects.

## 🎯 Repository Goals

- Learn React from basics to advanced concepts.
- Understand different state management approaches.
- Explore popular React libraries and tools.
- Build small, practical projects for each technology.
- Compare different approaches to solving the same problem.
- Improve React development skills through hands-on coding.

## 💻 Getting Started

### Prerequisites

Make sure you have installed:

- Node.js
- npm
- Git
- Visual Studio Code

### Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/react-learning-hub.git
```

### Navigate to Project

```bash
cd react-learning-hub
```

Each learning module contains its own project setup and dependencies.

Navigate to the required project folder and install dependencies:

```bash
cd 01-react-basics
npm install
npm run dev
```

> Note: The commands above assume the selected module has a Vite-based React setup.
